# TYT MD-UV390 — кодплаг с Android

Чтение и запись кодплага TYT MD-UV380 / MD-UV390 со смартфона через USB OTG
и штатный кабель программирования. Основной сценарий: один общий кодплаг,
у каждой рации меняется только Radio ID (и при желании имя и заставка).

## Как пользоваться

1. Один раз загрузите шаблон: «Открыть файл» → общий `.rdt` из CPS.
   Можно и прочитать рацию с готовым кодплагом и нажать «Сделать шаблоном».
2. Подключите рацию (OTG-переходник + кабель), **включите в обычном режиме**.
3. Введите Radio ID и имя → «Записать в рацию» (≈ 1 минута).
4. Если включён «ID +1», следующий ID подставится сам. Каждая запись попадает в журнал
   (можно выгрузить в CSV).
5. «Прочитать» после записи покажет ID/имя и сверит образ с записанным.

## Сборка

* Android Studio (Ladybug или новее): File → Open → эта папка → Run.
* Или GitHub Actions: workflow «Build APK» собирает `app-debug.apk`.
* Тесты логики кодплага: `gradle testDebugUnitTest`.

minSdk 31 (Android 12), Kotlin + Jetpack Compose.

## Устройство

| Файл | Что делает |
|---|---|
| `usb/DfuDevice.kt` | DFU поверх `UsbDeviceConnection.controlTransfer` + команды TYT (0x91/0xA2) |
| `usb/Uv390Programmer.kt` | последовательности чтения/записи, стирание, переадресация блоков |
| `codeplug/Codeplug.kt` | разбор `.rdt`/`.bin`, поля Radio ID / имя / заставка, CRC DFU-суффикса |
| `ui/` | экран, журнал, работа с файлами |

Память кодплага в рации: `0x000000–0x03FFFF` и `0x110000–0x19FFFF` (всего 0xD0000 байт).
Поля (смещения в `.bin`; в `.rdt` +549): заставка 0x2040 / 0x2054 (UTF-16LE, 10 симв.),
Radio ID 0x2084 (3 байта LE), имя 0x20B0 (UTF-16LE, 16 симв.).

Протокол и раскладка взяты из открытых проектов md380tools (Travis Goodspeed и др.)
и editcp / dalefarnsworth-dmr (Dale Farnsworth, LGPL-3.0); код здесь написан заново на Kotlin.

## Ограничения

* Только MD-UV380/UV390 (и совместимые RT3S, MD-2017 с тем же размером кодплага). MD-380 отклоняется.
* Прошивка (firmware) не поддерживается — только кодплаг.
* Кириллица в имени записывается, но отобразится только если её поддерживает прошивка рации.
